개인정보처리방침

시행일 2026년 11월 9일

소개개인정보처리방침이용약관

1. 처리하는 정보

  • 구글 계정 정보: 이메일 주소, 이름, 프로필 사진(로그인 확인과 권한 판정, 화면 표시용)
  • 업무 데이터: 사용자가 입력한 장비 정보, 대여자 이름·연락처, 대여·반납 기록

2. 저장 위치

업무 데이터는 사용하는 조직의 구글 스프레드시트에만 저장되며, 이름·연락처 등은 암호화해 저장합니다. 로그인 정보는 프로그램을 설치한 PC 안에만 보관됩니다. 개발자는 별도 서버를 운영하지 않으며, 사용자 데이터를 개발자에게 보내거나 수집하지 않습니다.

3. 구글 API 사용 범위

  • 로그인 확인(openid, 이메일, 프로필)
  • 조직의 구글 스프레드시트 읽기·쓰기(spreadsheets)
  • 프로그램이 만든 파일 관리와 시트 공유 대상 확인(drive.file, drive.metadata.readonly)
  • 조직의 휴대폰 대여용 Apps Script 설정(script.projects, script.deployments)

ERMS가 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 받은 정보는 위 기능에만 쓰며, 광고·판매·제3자 제공에 쓰지 않습니다.

4. 외부 통신

프로그램은 구글(스프레드시트·Apps Script)과 업데이트 확인을 위한 GitHub 공개 저장소에만 접속합니다.

5. 보관과 삭제

업무 데이터는 조직의 스프레드시트에서 관리자가 삭제할 수 있습니다. PC에 남은 로그인 정보는 프로그램에서 로그아웃하거나 프로그램 폴더를 지우면 삭제됩니다. 구글 계정의 서드 파티 연결에서 ERMS 접근 권한을 언제든 해제할 수 있습니다.

6. 문의

개인정보 관련 문의는 erms-support@googlegroups.com 또는 사내 담당자에게 해 주세요.
